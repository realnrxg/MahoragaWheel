### Mahoraga Wheel
Adds the Wheel of Adaptation from jjk above the head of ur player

- This is visual only it does not add any custom features

Requires: 
- Fabric Loader: 0.18.2+
- Supported Versions: 1.21.11

| Command | Description |
|---|---|
/mahoraga off | turns the wheel off
/mahoraga on | turns the wheel on
/mahoraga color gold | changes the color to gold
/mahoraga color white | changes the color to white

build
```
gradlew build
```
